# 💼 Sistema de Folha de Pagamento COBOL

Projeto desenvolvido em **COBOL** simulando um sistema corporativo
de processamento de folha salarial.

O objetivo deste projeto é aplicar conceitos utilizados em ambientes
**Mainframe**, especialmente em sistemas bancários, financeiros e
grandes empresas que utilizam processamento batch.


---

# 🚀 Sobre o Projeto

O **FOLHAPAG** representa um sistema simples de gerenciamento de
funcionários e cálculo salarial.

O programa permite:

✔ Cadastro de funcionários  
✔ Armazenamento de dados pessoais  
✔ Processamento de salário bruto  
✔ Cálculo de desconto INSS  
✔ Cálculo de salário líquido  
✔ Consulta das informações cadastradas
